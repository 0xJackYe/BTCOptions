# Frontier 卖方研究独立复审

复审范围：`research/options_sandbox/frontier/pricing.py`、`optimize.py`、`engine.py`，以及引擎反例测试。这里只读取源码、协议和单测，不使用正式搜索、验证或最终测试的收益排名选择参数。

## 已发现并修复的协议不一致

原协议宣告每次开仓名义额最多为 NAV 的 3 倍，但引擎实际比较的是钱包 Adjusted Equity。期权浮亏时二者不同：钱包余额 1,000、原持仓 ask/平仓费负债 400、新卖单净收入 10、新单 ask/平仓费负债 12，成交后 NAV 为 598；2,000 的总名义额不能被 3×598 的限制允许，旧钱包比较却允许。

根代理在没有产生正式 search 路径文件或收益排名时停止了该轮及进程池，使用全新种子重新冻结协议。引擎只修改了开仓名义风险预算，官方标准账户的 IM/MM 仍使用钱包 AE；没有把空头 mark 再从 AE 扣除。

修正后的预算为：

```
post_wallet = wallet + 新单净卖出收入
post_NAV = post_wallet - 原持仓ask/预计平仓费负债 - 全部新腿ask/预计平仓费负债
原名义额 + 全部新腿名义额 <= lever × post_NAV
原实际IM + 全部新腿IM <= 0.8 × post_wallet
```

这限制的是每次开仓时的比率。之后跳空或浮亏可以使比率超过 3，不能宣传整个路径始终保持 3 倍以内。

新增测试覆盖上述手算、正好 1,794 的边界和超出边界的拒绝，以及两腿分别可行但合计不满足 post-NAV 预算时整组拒绝。引擎 20 项实质测试通过。

## 因果、费用与数量核对

- 决策读取已收盘小时：先冻结行权价、到期日和上一小时 bid 减固定一 tick 的限价。报价缺失时不产生订单。下一小时收盘按该固定合约的实际 bid 检查限价，并重检每腿净收入、全部资金和数量限制。
- 旧仓先经过该小时 high→low 和 low→high 两种压力顺序；选择较差账户，再检查收盘风险、普通退出，最后才尝试前一小时的待成交新单。新单不会倒用成交前的 high/low 被强平。普通止盈止损不会在未知盘中路径上捡便宜。
- 日内风险的 IV 由上一小时 IV 加预先固定的价格冲击压力得到，普通退出才用当前收盘报价。未来价格修改不改变先前活跃报价和每日 NAV 的测试通过。
- 每条真实成交腿数量固定为 0.01 BTC，`maxpos` 限制实际腿数。双卖需 Put 与 Call 同到期、全部限价/净收入/随机成交和合计预算都通过才一起进入；退出可独立。没有把未成交 Call 的 Put 单腿结果冒充双卖。
- 空头买回按 ask 加手续费；入场按 bid 扣手续费；清算包括平仓交易费和清算费，先重算风险再决定是否继续部分清算。平仓不保留维护保证金。期末未平仓按 ask 和预计平仓费计负债。结算用小时收盘价的代理口径，含结算费。

复审未发现修正后剩余的费用漏扣、份数膨胀、短期 mark 双扣或标准账户保证金残留问题。

## 搜索程序与证据边界

搜索、验证、测试使用不重叠的预声明随机种子；搜索为 90 天，验证及最终测试为年度。三个方向的核心参数网格对称，另单列旧 C 的固定数量对照。每组候选共用市场路径及执行随机数；联合路径重抽样维持配对关系。最终测试使用冻结候选，不按最终收益局部细调。

HAR 的前向 RV 仅作为 2020–2023 训练目标，目标窗口结束早于 2024；活跃模拟报价由当时及此前的收益、慢 IV 状态和固定模型配置计算，没有读取模拟未来 RV。当前 SSVI 仍只来自一次公开截面；2023 的 IV 状态与现在/未来未得到时间外认证。

以下限制仍应保留在结果说明中：

1. high/low 两种顺序是预声明的保守压力近似，不是覆盖所有真实路径的数学上界。盘中 IV、流动性和实际先后顺序没有被重建。
2. 两腿成对入场是协调执行近似，真实币安两张订单不能假定具备原子成交保证。最小 lot 使用整笔成交/未成交，未模拟更小部分成交或撮合队列。
3. 风险资格中的亏损频率、CVaR 和回撤都是有限路径估计值；均值的同时置信下界不自动给这些风险约束提供置信保证。即使零次清算，未来清算概率也不能称为零。
4. 新种子是模拟内泛化，不能把已查看的历史重新变成首次真实市场留出。预测价格、风险中性曲面与真实执行仍未完成联合动态校准，研究候选不能称为全球或实盘最优。
