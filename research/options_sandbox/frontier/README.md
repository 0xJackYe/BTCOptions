# 新随机市场与 Put / Call / 双卖研究

此目录在上游 `60df266` 基础上修复执行与账户计算，比较三种卖方方向。它只做离线研究，没有账户连接或下单功能。路径来自随机模型，不能保证等同未来市场；最终结论以独立市场诊断和冻结的策略测试共同判断。

## 从干净仓库运行

在父目录按原说明安装依赖并执行 `prepare_data.py`，准备本地公开 BTC 小时资料。随后在本目录运行：

```powershell
python -m unittest discover -s . -p "test_*.py"
python optimize.py --smoke --workers 2 --out smoke-results
python validate.py --paths 128 --out market-validation-final
python optimize.py --workers 4 --out results
```

输出目录必须是新的；程序拒绝覆盖冻结协议。正式与 smoke 使用互不重叠的种子。smoke 是程序检查，不是收益证据。完整研究先冻结 `protocol.json`，然后冻结候选名单，最后才打开最终测试种子。不要通过不断换种子直到盈利来选策略。

## 价格怎样超越历史重采样

历史只负责估计参数，两个主模型的下一次价格变化由新的连续随机数产生：

1. `regime_jump`：正常/高波动状态随机切换，状态内随机波动率，正负双指数跳跃，价格跳跃与波动率共震。
2. `sv_jump`：连续随机波动率与独立的新跳跃；加入从训练数据多期限自相关估计的慢/快波动因子，保留周/月持续性。
3. `bootstrap_reference`：连续历史片段抽样，仅作为历史参考，不能把它和前两种新冲击发生器混为一谈。

主模型每小时对数变化可以概括为：

`r = annual_log_drift/8760 − lambda*E[J] + sigma/sqrt(8760)*Z + sum(J)`。

`Z` 是新高斯冲击；跳跃数量由 Poisson 随机过程产生；每个跳跃幅度是新双指数抽样。波动率和市场状态也会随机改变。补偿项防止正负跳跃的平均值意外改变指定对数漂移。零平均对数漂移不等于零平均价格收益。

价格和波动率没有为了保护卖方而设置经济上限；浮点越域明确失败，不丢弃路径。每小时有8个子步，并用 Brownian bridge 抽取子步内部高低点。高低点的精确联合顺序仍未知，不能当作真实逐笔行情。

固定 seed 复现同一世界；延长未来期限不能改写过去；不同 seed 产生不同终点和新行情组合。随机性还要和历史市场分布比较：尾部、波动率、波动聚集、自相关、跳跃频率和回撤。随机检验通过不代表拟真检验通过。

## 校准与报价

价格拟合只使用2020–2023；2024用于市场模型检查和结构选择，2025–2026以前已经看过，只能作为历史诊断。首次市场检查发现周尺度波动记忆不足，因此在任何策略盈亏产生前，用训练期多滞后波动率自相关加入慢因子；旧失败诊断保留。复用2024做结构选择后，不再把它称作完全未见测试。

报价层在 `pricing.py`：过去1天/7天/30天RV经 HAR 预测未来14天波动率；HAR未来目标必须结束于2024以前。2023公开 IV 重建资料估计水平与慢速残差，当前冻结的 SSVI 截面为2026-11-03公开报价。根据各执行价/期限IV，用原 Black–Scholes 函数计算 mark/Delta，再合成买卖报价与缺报价状态。

这仍是 P 测度价格与研究用报价层的组合，没有验证严格联合风险中性动态。一次当前截面无法证明未来 IV/偏斜和成交。价差、失约与可用率是压力假设，没有冒充真实撮合统计。

## 修复后的账户与执行

- 固定每个成交腿 **0.01 BTC**，maxpos 数的是实际腿数。纯1,000USDT，无现货转换；三种方向使用相同限制。
- 标准账户短仓 Adjusted Equity 使用钱包余额；空头 mark 留在维护保证金中，不重复扣减。阈值 MM/AE≥95%，保留研究用清算费用缓冲；平仓后立即重算。
- 强平风险在普通收盘止损前检查；旧仓对 high→low、low→high 两种盘中顺序取更差结果，属于保守压力近似，不能视为所有真实路径的严格损失上界。新单在该小时末成交，不倒用此前极值。
- 前一小时固定K、到期日及卖限价，下一小时满足限价才成交。基础限价允许1个5USDT档位，另测0档容忍；全部方向同口径。
- 双卖成对报价入场，两个腿都满足条件才成交，退出独立。协调双腿执行是近似，真实不同步成交和风险仍待实测。
- 扣开平仓/行权/清算费用。失约或无报价时普通止损无法成交。期末空头按ask及买回费记负债。
- 到期以小时指数代理结算，不能还原官方结算窗口；跳空止损不构成最大亏损保证。Call 空头的理论上行损失没有上限。

## 搜索与判断

有限网格216组：方向 Put/Call/双卖；目标期限7/14/28天；绝对Delta .05/.10/.20；止盈70%/90%；买回成本止损2倍/3倍；每日定时或方向化3%反向择时。再加旧C规则在新固定数量引擎中的对照，共217组。实际到期是周五合约中最接近目标的一个，执行价使用有限网格。

仓位最多4腿、每次开仓时名义金额上限为成交后经济净值的3倍，不优化杠杆，单腿最低净权利金0.5USDT。浮亏与跳空之后比率仍可上升，这不是持续再平衡或亏损倍数上限。保证金仍按钱包AE另算，两个概念不能混用。双卖需要两个腿各自达标，可能不成交；不能把不成交误当成低风险盈利策略。此处纯现金期权账户不包括核心BTC，Call按裸卖评估。

搜索每模型24条90天路径，按三种漂移筛选；每方向前两名进入128条年度路径验证；每方向冻结一名后，用512条年度路径测试，并保留C对照。验证/测试包含熊/平/牛、IV变薄并恶化执行、反转偏斜、被动限价六种情景。每个候选使用同一组市场和执行随机数，以配对盈亏比较。

目标是最大化各市场/情景中最差的平均净收益置信下界；纯现金基准为0。联合重抽样考虑候选与情景的同时比较，区间只反映模型内抽样误差。研究风险预算要求没有观察到强平/破产、最差5%平均收益不低于−30%、亏损超过30%比例不高于2.5%、回撤95分位不超过35%、平均每年至少2腿。这些是预先指定偏好，不是数学普适最优常数。

验证阶段风险/下界未通过的候选保留为失败诊断，不能只靠最终样本幸运晋级。没有合格者时保留现金，不强制找赢家。即使模型内有合格者，未来期权市场与真实执行适配尚未验证，也不能自动推广实盘。
