# BTC期权策略V1：通俗说明与固定规则

**已固定的是一份研究规则，不是已证明赚钱或最优的实盘策略。** 下面的资金只是模拟示例，不是真实账户余额。代码不连接账户、不下单。

## 一句话

长期保留大部分比特币，用一小部分比特币和单独准备的现金，在急跌后卖Put、急涨后卖Call；愿意低位增加少量现货，也愿意高位减少少量现货。收权利金的代价是承担进一步下跌和让出部分上涨收益。

## 1. 钱和币先分开

示例持有0.10BTC，其中0.09BTC长期保留。只用另外0.01BTC，加1,000USDT现金做策略。

- 每边最多卖0.01BTC名义量，不连续加卖。
- 策略现货最多增加到0.02BTC。到上限后不再卖新的Put；没有足够现货时不卖Call。
- 每笔Put预留 `行权价×0.01×110%` 的现金，同时开新仓和买现货后保留至少200USDT。
- Call对应的BTC锁定，在Call确认关闭前不出售。
- 不借款，不从0.09BTC核心仓自动补钱，不因收到权利金扩大数量。

例如70,000行权价的0.01张Put，预留770USDT。这笔钱在Put没关闭前，不能另外拿去买现货。

## 2. 跌了怎么做，涨了怎么做

只看已经结束的小时线，不看还在变化的当前小时。

| 方向 | 开始观察 | 后续确认 |
|---|---|---|
| 卖Put | 过去24小时跌幅首次达到3% | 此后12小时内，某个完整小时反弹至少0.25%，同时24小时跌幅仍达到3% |
| 卖Call | 过去24小时涨幅首次达到3% | 此后12小时内，某个完整小时回落至少0.25%，同时24小时涨幅仍达到3% |

确认以后还要选约和检查资金。有信号却没有合格合约，就不交易。不是每天强制双卖；两边条件先后满足、到期日一致时，才可能同时持有两腿。

单日涨跌绝对值达到10%时暂停新仓；同方向平仓后至少等24小时。不在已有同方向仓位上加码。

## 3. 选什么期权

| 条件 | 固定V1值 |
|---|---|
| 标的 | BTC，USDT报价和现金结算 |
| 剩余期限 | 10—20天，排序优先接近14天 |
| Put行权价 | 现价的75%—90% |
| Call行权价 | 现价的110%—125% |
| 买方Delta绝对值 | 0.05—0.15，排序优先接近0.10 |
| 标记IV／过去20天RV | 至少1.20 |
| 卖出报价对应IV | 不低于RV20 |
| 买卖价差／中间价 | 不超过20% |
| 费用门槛 | 权利金减预估开平仓手续费后至少1USDT，尚未扣平仓权利金 |
| 两腿到期日 | 相同 |

排序依次看期限接近14天、Delta接近0.10、扣费后权利金、价差和合约代码。

这些数值都是固定的待检验假设。14天和Delta0.10没有被证明最好，IV/RV达到1.20也不能保证正期望。Delta是价格敏感度，不是真实亏损概率。

## 4. 什么时候退出

- 扣除预计买回费用后的利润达到初始净权利金60%，就买回期权止盈，现货不动。
- 剩余时间不超过72小时，就关闭期权，现货不动。
- Delta绝对值达到0.35，或价格碰到行权价，关闭对应期权。Put关闭后按预算尝试买入0.01BTC；Call关闭后才尝试卖出对应0.01BTC。
- 买现货不得突破0.02BTC库存、现金储备和200USDT底线。不满足就只关期权，不强行买币。
- 保证金比例或净值触发全局风控时，关闭期权并停止买入现货；不进行上述单腿现货转换。
- 不滚仓，不靠卖更多期权补亏损。

## 5. 风险怎么控制

开仓后初始保证金／期权账户调整后权益不超过35%，维持保证金比例不超过20%。比例达到30%停止新仓，达到50%关闭期权风险。开仓还需通过72个价格、IV、时间压力场景。

策略净值从高点回撤25%时关闭期权、停止买入并暂停至少30天，已有BTC继续保留。所以25%是触发线，不是保证亏损止于25%。

现货覆盖Call是经济覆盖。普通账户中的BTC不会自动给期权钱包增加USDT保证金；组合上涨赚钱时，期权钱包仍可能缺钱。

币安标准BTC期权用USDT现金结算。到期赔付不会自动收到或交出BTC，现货买卖是另一个动作。

## 6. 现在能得出什么结论

V1规则已明确，但还不能认定值得自动实盘。当前研究模拟没有证明它稳定优于“同样的BTC和现金一直持有”。

沙箱是小时级研究变体：最早下一小时按固定合约和限价成交；合约挂牌、盘口和异常到期结算包含模型假设，不能当成秒级真实交易所回测。
